바른자세 지키미

※ 의료 진단 도구가 아닙니다. 카메라 기반 자세 습관 모니터링 도구입니다.

사용 방법 (열기/닫기)
  1. 카메라 권한을 허용해주세요.
  2. 앉은 방향에 맞게 정면 모드 또는 옆모습 모드를 선택하세요.
  3. 허리를 펴고 바르게 앉은 상태에서 기준 자세 저장 버튼을 눌러주세요. (모드마다 따로 저장해야 해요)
  4. 이후 자세가 기준보다 나빠지면 아래 상태 표시와 화면 속 곡선이 빨간색으로 바뀝니다.
  5. 나쁜 자세가 계속되면 화면 위쪽에 경고 문구가 나타납니다.
